# 🕵️ The Department Files

*A Console-Based Thriller Mystery Investigation Game in C++*

## 📖 About the Project

The Department Files is an interactive, story-driven mystery game built entirely in C++. Players step into the role of an investigator who receives a mysterious message leading them to Classroom 214 late at night. As the story unfolds, they explore different departments, solve puzzles, collect evidence, and uncover the truth behind a secret experiment hidden within the college.

The game combines storytelling, exploration, puzzle-solving, and decision-making to create an engaging text-based adventure.

## 🎮 Gameplay Overview

1. Receive a mysterious anonymous message.
2. Investigate **Classroom 214**.
3. Search for clues and collect evidence.
4. Visit different departments across the college.
5. Solve riddles and unlock hidden discoveries.
6. Build your case using collected evidence.
7. Make the final decision that determines your fate.

## 🚀 How to Run

1. Clone this repository.

```
git clone https://github.com/suhanimadan/the-department-files.git
```

2. Open the project in any C++ IDE (Code::Blocks, VS Code, Dev-C++, etc.).

3. Compile the source file.

g++ main.cpp -o game

## 📸 Game Story

Late one evening, an anonymous message summons you to Classroom 214.

As you investigate, mysterious clues point toward a long-forgotten experiment conducted inside the college. Strange messages, hidden evidence, and abandoned departments slowly reveal a conspiracy that someone desperately wants to keep buried.

Will you uncover the truth... or become the next victim?
