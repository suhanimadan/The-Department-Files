The Department Files

A text-based thriller mystery game built in C++.

Story:

The game begins with a mysterious message asking the player to visit Classroom 214 late at night.

As the investigation continues, the player explores different college departments, uncovers hidden evidence, receives threatening phone messages, and slowly discovers a dark secret hidden inside the campus.

Features:

- Department exploration
- Evidence collection system
- Threatening phone messages
- Story-based progression
- Chapter-style storytelling

Technologies Used:

- C++
- Functions
- Vectors
- Conditional Statements
- Loops
- Menu-Based Navigation

Current Status

Chapter 1 completed.
